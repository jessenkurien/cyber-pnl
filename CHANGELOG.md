## [0.1.0] — 2026-09-14

- Ten fictional, calibrated cyber-loss scenarios for an illustrative SaaS company.
- Seeded Monte Carlo simulation, loss exceedance reporting, control counterfactuals, investment
  ranking, and endpoint sensitivity analysis.
- Strict model validation, governed evidence, digest attestations, and operational publication gates.
- Board statement, CFO brief, methodology, calibration, model-risk, GRC, implementation, and launch
  documentation.
- Automated quality gates with more than 90% test coverage.
- Formal software citation metadata and an explicit attribution request.
- Currency-aware financial formatting using the model's three-letter currency code.
- A GitHub-ready social preview and international-use guidance.
- Search-oriented project metadata for cyber risk quantification, security economics, and
  investment decision support.
- Bounded simulation and evidence-file resource limits for safer processing of untrusted models.
- Responsive, keyboard-scrollable report tables and accessible labels for generated SVG charts.
- GitHub issue forms, a pull-request checklist, and an explicit author release-approval record.
- Validated finite KPI imports that fail safely before replacing model evidence.
- A stable, edition-specific IBM 2025 source URL instead of an evergreen report page.
